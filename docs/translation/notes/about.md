# Translator notes: es/about.html and visitor-count.js

Files: `es/about.html` (full page) and the `es` entries of `STRINGS` in `assets/js/visitor-count.js`.
Checks run: `python3 scripts/check-i18n-parity.py` (PASS; ids, tel: links, classes and tag order identical to the English page) and `node --check assets/js/visitor-count.js` (OK).

General approach in the Sources list: each link keeps the English title of the cited document and gets " (en inglés)". Only the metadata inside the link text was put into Spanish: dates ("Oct. 2026" -> "octubre de 2026"), "draft" -> "borrador", "Illinois law:" -> "Ley de Illinois:", "Illinois HFS" -> "HFS de Illinois", plus the glossary's first-use glosses (CMS, HHS, VA, Attorney General, statute names). Where link-map.md lists a verified Spanish URL, the href was switched and the Spanish document title used where link-map gives one. Descriptions (`source-for`) are fully translated.
